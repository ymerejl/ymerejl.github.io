How to Set Up the Castles S1F2 (Saturn 1000F2) and S1F2L (Saturn 1000F2L) Payment Terminals

Learn how to set up and use the Castles S1F2 (Saturn 1000F2) and S1F2L (Saturn 1000F2L) payment terminals.

September 25, 2026

 

This article is a manual to assemble and configure the Castles S1F2 (Saturn 1000F2)  and S1F2L (Saturn 1000F2L) payment terminals.

 

The Castles S1F2/S1F2L devices are all-in-one payment terminals that include an integrated printer. The S1F2L variant is equipped with an infrared (IR) barcode scanner in addition to the built-in camera.

📒 NOTE

Before you begin the setup and configuration process, it is important that the device is boarded and assigned to a store in your  Adyen Customer Area. 

 

 

Prerequisites:

The device is configured in the Adyen Merchant Account.

Make sure that the location where the device will be used has internet access.

 

📗 TIP

You can connect the device via Wi-Fi, or a 4G network.

 

The device is plugged into a power outlet. 

The  Ventrata terminal app is pushed to the device.

 

Set up Device with Adyen

Turn on the device.

Select the device language. 

 

Select Language

 

For Wi-Fi connection, on the Setup Wi-Fi page press the + button to add a Wi-Fi connection.

 

Setup Wi-Fi 

 

Toggle 'Use Wi-Fi' on. 

 

Use Wi-Fi 

 

Select and connect to your Wi-Fi network. 

The device may perform multiple updates and you may require the Adyen password to your device. Contact our Technical Support team to obtain the password.

 

When ready, the Ventrata terminal app should install automatically. 

 

📒 NOTE

If this is not the case, contact our Technical Support team and provide the device's serial number so they can push the app to the device.

 

You can find the Serial Number on the back of the device (copy the number following S/N).

 

Serial Number

Watch this video of the Castles S1F2 & S1F2-L assembly and setup:

 

 

Create the Terminal in Ventrata

To use a Castles payment terminal with the  Ventrata terminal app, create a terminal entry for the device in the Ventrata dashboard.  

📒 NOTE

Before you create the Ventrata config, make sure the device has been boarded and assigned to a store in your  Adyen Customer Area. 

Go to Ticket Terminals > Terminals.

 

Terminals 

 

If you use Destinations, select the destination for which you want to add the new terminal.

 

Destination 

 

Press the + New Terminal button.

 

New Terminal 

 

Enter ‘Name’.

 

Terminal Name

 

📗 TIP

Use a clear, descriptive name by combining details like brand, device model, and device type, and the last 3 to 4 digits of the serial number, for example, 'Adyen - Castles S1F2 - 4321'

 

Enter the device’s serial number.

 

Serial Number

 

📗 TIP

You can find the Serial Number on the back of the device (copy the number following S/N).

 

Serial Number

 

Check or change the destination in which the terminal device will be used.

 

Destination

 

Select an Adyen payment gateway.

 

Gateway 

 

Select the Terminals mode.

 

Mode - Terminals 

 

Press the Create Terminal button.

 

Create Terminal
