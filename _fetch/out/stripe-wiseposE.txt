Das BBPOS WisePOS E ist ein Tischlesegerät für Stripe Terminal-Apps. Es stellt eine Verbindung zum Stripe Terminal SDK über das Internet her.

Dieses Lesegerät ist mit den folgenden Integrationen kompatibel: JavaScript SDK, iOS SDK, Android SDK, React Native SDK und servergestützten Integrationen.

Für die Lesegeräte BBPOS WisePOS E empfehlen wir die servergestützte Integration, die die Stripe API anstelle eines Terminal SDK verwendet. Informationen zu den Bestandteilen und Merkmalen des Lesegeräts finden Sie im BBPOS WisePOS E-Produktblatt.

Fehler am Lesegerät beheben

Stellen Sie sicher, dass Ihr Netzwerk alle unsere Netzwerkanforderungen erfüllt, und führen Sie die Schritte im Abschnitt Netzwerkfehlerbehebung aus.

Bei der Fehlerbehebung helfen Ihnen die folgenden häufigen Szenarien, mit denen sich das Problem diagnostizieren lässt.

Diagnose ausführen

Der BBPOS WisePOS E enthält integrierte Diagnosefunktionen, mit denen Sie Verbindungs- und Konfigurationsprobleme erkennen können. Wir empfehlen, diese Diagnosen als ersten Schritt auszuführen, wenn Sie Probleme mit einem Lesegerät beheben.

So rufen Sie das Diagnosemenü auf:

Wischen Sie vom linken Bildschirmrand Ihres Lesegeräts nach innen.
Tippen Sie auf Einstellungen.
Geben Sie den Admin-Passcode ein. Der Standardwert ist 0-7-1-3-9.
Wählen Sie Diagnose aus.

Im Diagnosemenü werden Testergebnisse und Informationen zu Ihrem Lesegerät angezeigt:

DNS-Auflösung: Überprüft, ob das Lesegerät Domainnamen auflösen kann.
Stripe-Konnektivität: Überprüft, ob das Lesegerät eine Verbindung zu den Stripe-Servern herstellen kann. Dieser Test muss erfolgreich sein, damit Ihr Lesegerät Zahlungen verarbeiten und Updates empfangen kann.
Konnektivität von Terminal-Ereignissen: Testet die Verbindung des Lesegeräts mit der Stripe-Ereignisinfrastruktur.
WLAN-Informationen: Zeigt die WLAN-Frequenz und Signalstärke an (falls über WLAN verbunden).
Status der Batterie und Hardware: Zeigt den Zustand, die Spannung, die Kapazität und den Status der Dock-/Hub-Verbindung an.
Hinweis

Wenn der Stripe-Konnektivitätstest fehlschlägt, kann Ihr Lesegerät keine Zahlungen verarbeiten oder Softwareupdates erhalten. Befolgen Sie die Schritte zur Netzwerkfehlerbehebung, um Verbindungsprobleme zu beheben.

Wir empfehlen, Diagnosen immer dann durchzuführen, wenn Probleme mit Ihrem Lesegerät auftreten oder als Teil Ihrer regelmäßigen Wartungsroutine, um potenzielle Probleme proaktiv zu identifizieren.

Das Lesegerät kann nicht angeschlossen werden.

Um die Konnektivität zu prüfen, navigieren Sie zu Einstellungen und wählen Sie dann WLAN-Einstellungen aus. Dadurch wird jedes verfügbare WLAN-Netzwerk angezeigt. Um weitere Informationen zur Verbindung zu erhalten, tippen Sie auf den Namen des verbundenen Netzwerks.

Wenn Sie Verbindungsprobleme haben, führen Sie die Diagnosetests durch, um die Konnektivität von Stripe zu überprüfen und die Ursache zu ermitteln.

Das Lesegerät kann keine Verbindung zum Ethernet herstellen, obwohl es an die Dockingstation angeschlossen ist.

Sie müssen beide Kabel anschließen, bevor Sie das Lesegerät in die Dockingstation einsetzen. Entfernen Sie das Lesegerät und setzen Sie es erneut in die Station ein.

Wenn das Problem weiterhin besteht, führen Sie die Diagnosetests durch, um die Netzwerk- und Stripe-Konnektivität zu überprüfen.

Das Lesegerät kann nicht aktualisiert werden.

Wenn Ihr Lesegerät nicht aktualisiert wird, kann es möglicherweise keine Verbindung zu Stripe herstellen. Führen Sie die Diagnosetests durch, um die Stripe-Verbindung zu überprüfen. Vergewissern Sie sich, dass der Stripe-Verbindungstest „Bestanden“ anzeigt. Wenn der Test fehlschlägt, führen Sie die folgenden Schritte aus.

Hinweis

Wenn Sie einen Router verwenden, lesen Sie das Handbuch Ihres Routers und konfigurieren Sie das Netzwerk-Setup neu.

Lesegerätesoftware von Stripe

Stripe stellt die Software bereit, die das BBPOS WisePOS E steuert. Das Lesegerät erhält automatisch Aktualisierungen von Stripe, wenn es nicht in Gebrauch ist. Diese können Verbesserungen und erforderliche Sicherheitsupdates von Stripe und unseren Hardwarepartnern enthalten. Wenn Softwareupdates für das Lesegerät zur Verfügung gestellt werden, aktualisieren Sie Ihr Lesegerät auf die neueste verfügbare Version, damit Sie Stripe Terminal weiter nutzen können. Wird ein erforderliches Update nicht installiert, kann ein Lesegerät keine Zahlungen mehr annehmen.

Das Lesegerät wird jeden Tag um Mitternacht neu gestartet, um die PCI-Konformität zu gewährleisten. Die Verbindung zur POS-App wird jeden Morgen getrennt. Lassen Sie Ihr Lesegerät eingeschaltet und am Strom angeschlossen, um automatische Software-Aktualisierungen zu erhalten. So wird sichergestellt, dass die Aktualisierungen um Mitternacht (in der Zeitzone des zugewiesenen Standorts erfolgen und der Betrieb nicht unterbrochen wird. Wenn Sie das Lesegerät nachts aus der Steckdose ziehen, kann die Aktualisierung beim nächsten Einschalten erfolgen. Wenn Sie manuell nach einer Aktualisierung suchen möchten, starten Sie das Lesegerät neu.

Softwareversion des Lesegeräts

Die Software des BBPOS WisePOS E besteht aus vier Komponenten: der Reader-Anwendung, der Firmware, der Konfiguration und der Schlüsselkennung. In der folgenden Tabelle sind die neuesten Versionen dieser Komponenten für die Länder zusammengefasst, in denen der BBPOS WisePOS E erhältlich ist. Die Versionen Ihres Readers finden Sie im Diagnosemenü.

Hinweis

In PCI-Listen hat die Firmware-Kennung das Format WSC5x.11-xxxxx-xxxxx. xxxxx steht dabei für einen Platzhalter für die ROM-Version bzw. die Firmware-Version. Alle Versionen sind PCI-konform.

Insbesondere wird eine PCI-Firmware-ID WSC5x.11-WXYZZ-ABCDD der ROM-Version W.X.Y.ZZ und der Reader-Version AA.BB.CC.DD zugeordnet. Beispielsweise wird WSC5x.11-18302-50127 der ROM-Version 1.8.3.2 und der Firmware-Version 5.00.01.27 zugeordnet. Wenn die ROM-Version nur drei Ziffern W.X.Y hat, nimmt ZZ den Wert 00 an.
